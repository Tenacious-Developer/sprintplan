Todo app: UI mockup (v1)

Static picture of the UI for spec.md. Nothing here is clickable. Dark theme, blue accent.

Decisions shown here (also in spec.md §6):
  • New todos go at the bottom. Spaces at the start and end of the text are trimmed.
  • "Clear completed" is hidden when no todo is completed.
  • Edit button to start editing; Enter / Save saves, Esc / Cancel cancels.
  • Delete and Clear completed ask for confirmation in an in-page dialog.
  • Dark theme only, blue accent.
